PASO 1: VERIFICAR QUE MYSQL ESTÁ CORRIENDO
──────────────────────────────────────────

• Abre "XAMPP Control Panel" (busca en Inicio de Windows)
• Haz click en botón "Start" en la fila de MySQL
• Espera 2-3 segundos hasta que diga "Running"
• También haz click en "Start" para Apache

Si aparece error, abre PowerShell como Administrador y ejecuta:

  e:\xampp\mysql\bin\mysql.exe -u root -e "SELECT 1;"

Si ves "1", MySQL está OK. Si error, reinicia XAMPP.

RESULTADOS POSIBLES:

✅ TODO OK:
   Te redirige a: http://localhost/prueba%20conexion%20php/admin/dashboard.php
   Ves una tabla con turnos (vacía o con datos)
   En la esquina superior derecha ves "admin" y botón "Cerrar Sesión"

❌ ERROR 404 - "Not Found":
   
   SOLUCIÓN:
   1. Verifica que Apache está corriendo (XAMPP Panel → Start)
   2. Abre la consola del navegador (F12 → Consola)
   3. Busca el mensaje de error rojo
   4. Verifica que la ruta es correcta en la barra de direcciones
   5. Si sigue fallando, abre PowerShell y ejecuta test_login.php de nuevo
      para ver dónde está el problema

❌ ERROR "Credenciales incorrectas":
   
   SOLUCIÓN:
   1. Verifica que escribiste bien: admin / admin123
   2. Abre PowerShell y verifica que admin existe en BD:
      
      e:\xampp\mysql\bin\mysql.exe -u root barberia -e "SELECT * FROM administradores;"
      
   3. Deberías ver una fila con usuario "admin"
   4. Si no existe, inserta:
      
      e:\xampp\mysql\bin\mysql.exe -u root barberia -e "INSERT INTO administradores (usuario, clave) VALUES ('admin', 'admin123');"

❌ ERROR "Error de conexión a la base de datos":
   
   SOLUCIÓN:
   1. Abre XAMPP Control Panel
   2. Haz click en "Start" en MySQL
   3. Espera 3 segundos
   4. Actualiza la página del navegador (F5)
   5. Si sigue fallando, ejecuta:
      
      &"e:\xampp\php\php.exe" "e:\xampp\htdocs\prueba conexion php\test_login.php"
      
      para ver el error detallado
